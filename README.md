# D&D 中文战斗追踪器

供地下城主使用的本地桌面程序。界面采用接近 VS Code 的深色工作区风格。仅使用 Python 标准库（Tkinter、JSON 等），无需 pip 安装第三方库；运行时完全离线。

## 界面布局

- 顶部：轮数、当前行动者，以及三个右上角图标按钮：开始战斗、下一位、结束战斗（图标来自 `resources/` 下的 SVG 文件）。
- 中间列表：本轮行动状态、类型、名称、先攻、当前 / 最大 HP 和零血量提示；右上角使用“人物＋”和“怪物＋”图标添加角色。
- 列表下方：先攻排序、同先攻上移 / 下移、移除所选角色。
- 右侧：选择角色或点击添加按钮时会自动展开参战者档案；可用右上角同风格的小号关闭图标隐藏，也可拖动分隔条微调宽度。
- 底部：伤害和治疗；最下方显示自动保存结果和重试按钮。

当前行动者以柔和绿色底色、粗体和“行动中”标记。鼠标选中的角色是血量操作对象，可能与当前行动者不同；请看名称和“本轮”列确认。0 HP 有红色文字及独立提示，不会自动删除、判定死亡或跳过回合。

## 在这台 Mac 上立即启动

当前 `python3` 已验证为 Python 3.15 + Tk 9.1，可直接从终端启动：

1. 打开 macOS 的“终端”（可按 Command + 空格，搜索“终端”）。
2. 复制下面两行并回车：

```bash
cd /Users/stevenyin/workspace/my-dnd-repo/battle_tracker
python3 battle_tracker.py
```

窗口打开后即可使用。跑团时保持终端开启，结束时关闭程序窗口即可。无需联网，也无需另外安装依赖。

如果启动失败，先检查当前 Python 是否带有 Tkinter：

```bash
python3 -m tkinter
```

该命令应弹出 Tk 测试窗口。若提示缺少 `_tkinter`，请为正在使用的 Python 安装匹配的 Tkinter，或使用包含 Tkinter 的 Python 官方安装包。不要运行 `pip install tkinter`，Tkinter 是 Python 的可选系统组件。

## 在其他电脑上安装和启动

代码兼容 Python 3.9 及以上；新安装时使用官网仍支持的 Python 3 版本。

- **macOS**：从 [Python 官方 macOS 下载页](https://www.python.org/downloads/macos/) 安装 Python。官网安装包包含 Tkinter，详见 [官方 Tkinter 说明](https://www.python.org/download/mac/tcltk/)。使用 `python3 -m tkinter` 检查，然后进入本文件所在目录，执行 `python3 battle_tracker.py`。
- **Windows**：安装 Python 3，并确保安装选项包含 Tcl/Tk 与 IDLE。打开保存这些文件的文件夹，在地址栏输入 `cmd` 回车，然后执行 `py -3 -m tkinter` 检查；关闭测试窗口后执行 `py -3 battle_tracker.py`。
- **Ubuntu / Debian 桌面系统**：如未安装 Tkinter，可运行 `sudo apt install python3-tk`，然后在本目录执行 `python3 battle_tracker.py`。

如提示找不到脚本，说明终端没有进入 `battle_tracker` 目录；如提示 `No module named '_tkinter'`，请为正在使用的 Python 安装匹配版本的 Tkinter。没有桌面的 SSH / 服务器会话不能显示这个桌面窗口。

## 一次战斗的操作顺序

1. 点击参战者列表右上角的“人物＋”或“怪物＋”图标，在右侧填写名称、类型、先攻和最大 HP，再点击“确认添加”。新增时当前 HP 留空就等于最大 HP；最大 HP 至少为 1，先攻允许负整数。
2. 添加怪物时输入基础名称，例如“哥布林”；程序会显示“哥布林 1”“哥布林 2”。第一只也有编号。编辑框显示基础名称，不要重复输入自动编号。现有怪物不会因为删除其他怪物而重新编号；新增编号取同名现存怪物最大编号加 1，删除末尾编号后可能复用该编号。每个角色仍有永不依赖名称的独立 UUID。
3. 点击“排序”，按照先攻从高到低排列；同先攻保留原有相对顺序。选中同先攻角色后点击“同先攻 ↑ / ↓”可交换相邻顺序，再次排序也会保留调整结果。
4. 点击 `▶`（开始战斗）：自动排序，从第 1 轮第一名开始。当前角色行动结束后点击 `>>`（下一位），列表选中项会自动跟随新的当前行动者。开始后不能重复点击开始以重置轮次。
5. 选中需要扣血的角色，在底部填入整数，点击“受到伤害”。伤害直接扣减当前 HP，但不会使 HP 低于 0。
6. “接受治疗”最多恢复到最大 HP。需要直接修改当前 HP 时，选中角色后使用右侧“当前 HP”字段并保存修改。
7. 单击角色后，右侧档案标题会显示其名称；修改资料后点击“保存修改”。修改最大 HP 时，如当前 HP 超过新上限，需要一并修正。修改先攻后点击“排序”才能重排。
8. 选择角色或点击添加按钮时，档案会自动展开到合适宽度，无需手动调整；如有需要仍可拖动分隔条微调。点击档案右上角的小号“×”可隐藏。
9. 点击右上角 `■`（结束战斗）会保留所有参战者、显示顺序、先攻与当前 HP，只清空轮数和本轮行动进度，回到可再次点击 `▶` 的准备阶段。

## 战斗中增删、排序的约定

程序保存当前行动者的独立 ID，以及本轮已经行动的 ID 集合，避免用列表位置判断当前回合。

- “下一位”先完成当前角色的行动，再从显示列表顶部寻找本轮尚未行动的第一名，并自动选中该角色。正常排序下就是依次向下推进。
- 重新排序或调整同先攻顺序，不会更换当前行动者，不会改变轮数。已经行动的角色本轮不会再次行动；尚未行动的角色即使被排到当前角色上方，也会获得回合。
- 战斗中新增角色加入本轮待行动名单，先追加在列表末尾；需要按先攻定位时点击“排序”。本轮不会因为其先攻更高而漏掉它。
- 移除当前行动者，立即选取本轮待行动名单中的第一名，轮数不变。如果本轮已没有待行动者，顶部提示“本轮已结束”，等 DM 点击“下一位”才进入下一轮。
- 正常完成本轮最后一名角色后，点击“下一位”进入下一轮。删除或排序本身绝不增加轮数。
- 删除所有角色后回到准备状态，轮数为 0；重新添加角色后点击“开始战斗”，从第 1 轮开始。
- HP 降到 0 不会自动结束战斗、删除角色或跳过回合；是否结束战斗由 DM 使用右上角按钮决定。
- 手动结束战斗不会清空参战者或恢复 HP；再次开始时会沿用当前数据并重新从第 1 轮排序行动。
- 这些规则只辅助回合排队，不自动处理死亡豁免、倒地、延迟行动、传奇动作或其他 D&D 规则。

## 保存与恢复

每次有效的新增、编辑、移除、血量修改、排序、回合推进和结束战斗都会自动保存，启动时自动恢复。保存包括显示顺序、独立 ID、血量、当前行动者、轮数和本轮已行动名单。

存档固定保存在脚本旁边，不受终端当前目录影响：

```text
/Users/stevenyin/workspace/my-dnd-repo/battle_tracker/battle_save.json
```

- 文件缺失：底部显示“未找到存档”，从空战斗开始，第一次修改后创建存档。
- JSON 损坏或内容不合法：中文提示原因，先把原文件复制为同目录的 `battle_save.json.invalid-随机ID.bak`，打开空战斗。不会静默覆盖损坏的原文件。
- 无法读取或备份原文件：保护原文件；保存前必须先成功备份，或者由你移走原文件。修复文件 / 目录读写权限后点击“立即保存 / 重试”。
- 保存失败：界面提示，内存中的战斗仍保留；点击“立即保存 / 重试”。退出时会再尝试保存，仍失败时询问是否放弃尚未保存的更改。
- 写入采用“同目录临时文件 → 刷新到磁盘 → 原子替换”，防止半份 JSON 覆盖上次完整存档。

同一份存档请只打开一个程序实例，避免多个窗口互相覆盖保存。程序不提供跨实例同步。
